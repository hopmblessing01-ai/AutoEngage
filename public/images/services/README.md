# Service images

Add PNG or JPG files here (code expects `.png` — rename or update `src/lib/service-images.ts` if you use `.jpg`).

| File | Used on |
|------|---------|
| `crm.png` | CRM card + detail hero |
| `crm-inline.png` | CRM detail sidebar |
| `workflow.png` | Workflow card + detail hero |
| `workflow-inline.png` | Workflow detail sidebar |
| `ai.png` | AI card + detail hero |
| `ai-inline.png` | AI detail sidebar |
| `consulting.png` | Consulting card on `/services` |

Recommended: **4:3** for `*-inline.png`, **16:10** or wider for card/hero images.
